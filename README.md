# WiFi File Share Pro ⚡

Welcome to the official distribution repository for **WiFi File Share Pro**. This is a lightweight, ultra-fast, and 100% offline Android application designed to share large files, documents, and media seamlessly across devices over your local WiFi network.

🔗 **Official Website:** [Visit Live Download Page](https://github.io)

---

## 🚀 Key Features

* **Zero Cellular Data Consumed:** Files are transferred strictly within your local network perimeter. No mobile data or active internet connection required.
* **Maximum Throughput Speed:** Utilizes the full bandwidth capability of your local WiFi routing standard for rapid data streaming.
* **100% Secure & Sandboxed:** Your data never leaves your room. No cloud storage dependencies, keeping your privacy completely intact.
* **QR Code Connection Handshake:** Simply launch the server, generate the network stream, and scan the dynamic QR code on the receiving device to connect instantly.
* **Optimized Architecture:** Built with native Java Sockets and structured XML metadata handler payloads for minimal RAM and CPU footprints.

---

## 📥 Installation Guide

1. Download the latest release distribution bundle directly: [wifi-file-transfer.apk](./wifi-file-transfer.apk).
2. Enable "Install from Unknown Sources" in your Android security settings if prompted.
3. Install the APK and launch the application.

### How to Use:
1. Ensure both sending and receiving devices are connected to the **same WiFi router or mobile hotspot**.
2. Tap **"Start Server"** on the receiving device to host the network stream.
3. Use the sending client device to either enter the generated local server IP address or scan the displayed **QR Code**.
4. Select your file packages and begin transferring!
